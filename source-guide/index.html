SOURCE DIRECTORY / EDITORIAL POLICY

多元信源，交叉验证

没有任何媒体在所有议题上绝对中立。我们按证据角色、机构属性、独立性、访问范围和来源关系使用信源，而不是按国别简单排名。

核心规则：原始文件证明机构发布了什么；通讯社和专业媒体帮助核验事件、采访各方和补充背景；区域媒体提供不同地理视角；国际组织提供数据；社交平台用于发现线索，未经核验不能单独支撑重大事实。

五、X / Twitter与社交媒体

X / Twitter用于发现官方账号公告、记者现场信息、学者观点、企业消息和公众反馈。账号身份应从机构官网反向核验；认证标记不等于内容正确。

  • 记录原帖URL、handle、发布时间、编辑状态和检索时间。
  • 图片视频执行反向搜索、地理定位、时间和上下文核验。
  • 重大事实不得仅由截图、匿名爆料、转发量或认证标记支撑。
  • 参考：X Authenticity Policy、AP Verification。

六、交叉验证规则

类型最低证据组合常见误区
政策法律正式文件 + 主管部门解释 + 实施报道把征求意见稿写成生效法规
外交政治当事方材料 + 通讯社 + 区域视角把一方表态写成双方共识
宏观统计原始数据 + 方法说明 + 国际比较混淆单月/累计、名义/实际
金融行情交易所/指数源 + 第二数据商混淆现货/期货、沪深/沪深北
民生社会政策文本 + 地方执行 + 全国统计/研究用少数案例推断全国覆盖
社交媒体账号身份 + 原始素材 + 独立来源把认证和截图当证据
独立性提醒：Reuters稿件被CNA和Straits Times转载时，只计一个Reuters来源；新华社稿件被多个门户转载同理。
