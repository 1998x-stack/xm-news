# XM News 信源目录与编辑规则

机器可读目录：[config/source-catalog.json](../config/source-catalog.json)。

## 原则：多元，不等于寻找一个“中立媒体”
不存在覆盖所有国家、议题和利益关系的绝对中立媒体。媒体所有权、商业模式、编辑传统、采访网络、司法辖区和议题立场都会影响报道。按证据角色使用：
- **P0 原始材料：** 官方文件、声明、统计表、监管规则、法院判决、公司公告。确认机构发布了什么，不自动裁定争议。
- **P1 独立报道/通讯社：** Reuters、AP、AFP等，用于独立采访、事件核验和当事方回应。
- **P2 专业/区域/研究：** Bloomberg、FT、The Economist、财新、第一财经、CNA、Nikkei Asia、SCMP、ISEAS等。
- **P3 社交媒体/个人账号：** X/Twitter等，只用于发现线索和观点；未经核验不作为重大事实唯一证据。

P0不代表中立；P1/P2也不是天然无偏。说明来源能证明什么、不能证明什么。

## 国内官方与原始来源
- [新闻联播](https://tv.cctv.com/lm/xwlb/) / [央视新闻](https://news.cctv.com/)：国家议程、政策、重大事件；区分节目、文字稿和第三方整理。
- [人民日报](https://paper.people.com.cn/) / [人民网](https://www.people.com.cn/)：官方政策议程、基层治理、社会议题；评论代表机构立场。
- [求是网](https://www.qstheory.cn/)：党的理论和政策阐释，不是独立社会调查。
- [新华社](https://www.news.cn/)：国内外重大新闻、外交、政策；多站转载同稿只算一条来源链。
- [中国政府网](https://www.gov.cn/)：国务院政策、法规、公报；实施效果另行核验。
- [外交部](https://www.mfa.gov.cn/)：外交声明和会谈；同步寻找对方官方材料。
- [国家统计局](https://www.stats.gov.cn/)：生产、消费、投资、人口、就业、价格；核查统计期、名义/实际和修订。
- [人民银行](https://www.pbc.gov.cn/) / [外汇局](https://www.safe.gov.cn/)：货币政策、利率和汇率；区分政策、操作和市场传导。
- [发改委](https://www.ndrc.gov.cn/) / [财政部](https://www.mof.gov.cn/) / [海关总署](http://www.customs.gov.cn/)：规划、投资、财政、贸易和能源。
- [人社部](https://www.mohrss.gov.cn/) / [民政部](https://www.mca.gov.cn/) / [卫健委](https://www.nhc.gov.cn/) / [教育部](https://www.moe.gov.cn/)：就业、社保、养老、医疗和教育；草案、正式规章、地方试点分开。
- [上交所](https://www.sse.com.cn/) / [深交所](https://www.szse.cn/) / [北交所](https://www.bse.cn/) / [港交所](https://www.hkex.com.hk/)：交易规则、市场数据和公司公告。

## X / Twitter与社交媒体
用于发现官方账号公告、记者现场信息、学者观点、企业消息和公众反馈。从机构官网反向找到官方账号；记录原帖URL、handle、发布时间、编辑状态和检索时间；图片视频做反向搜索、地理定位、时间/天气/地标核验。截图、匿名爆料、转发量和认证标记不能独立证明事实。重大政治、金融、公共安全和伤亡信息不得仅由社交帖子支撑。参考：[X Authenticity Policy](https://help.x.com/en/rules-and-policies/authenticity)、[AP Verification](https://www.ap.org/solutions/verify/)。

## 交叉验证与独立性
| 类型 | 最低证据组合 | 常见误区 |
|---|---|---|
| 政策/法律 | 正式文件 + 主管部门解释 + 实施报道 | 把征求意见稿写成生效法规 |
| 外交/政治 | 当事方材料 + 通讯社 + 区域视角 | 把一方表态写成双方共识 |
| 宏观统计 | 原始数据 + 方法说明 + 国际比较 | 混淆单月/累计、名义/实际 |
| 金融行情 | 交易所/指数源 + 第二数据商 | 混淆现货/期货、沪深/沪深北 |
| 民生社会 | 政策文本 + 地方执行 + 全国统计/研究 | 用少数案例推断全国覆盖 |
| 社交媒体 | 身份核验 + 原始素材 + 独立来源 | 以认证、截图、转发量当证据 |

Reuters稿件被CNA和The Straits Times转载，只计一条Reuters来源；新华社稿件被多个门户转载同理。每条重要主张记录claim_id、source_id、URL、发布者、发布时间、检索时间、定位、来源类型、机构立场、独立性分组、核验状态、访问限制、反证和置信度。
