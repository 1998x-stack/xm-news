# XM News Visual System｜Four Pillars

Shared visual accents: Politics muted violet; Finance deep teal; Economy warm ochre; Livelihood forest green. Color is a navigation cue, not a substitute for labels.

## Portal
Brand/date → cross-pillar thesis → four clickable pillar cards → key facts → source method → archive. The portal is an overview, not a fifth mixed article.

## Pillar page
Pillar/date/as-of/confidence → one-sentence thesis → 3–4 facts → timeline/original SVG → facts/background → source comparison → mechanism → counter-evidence → limitations/risks → watchlist → linked sources.

## Chart rules
Label dates, units, axes and source IDs. SVG includes title, desc, role=img, aria-labelledby and figcaption. Distinguish data charts from conceptual diagrams. No fake precision or copied publisher graphics.

## Accessibility
One H1, semantic H2/H3, main/nav/section/figure/figcaption/table/caption, visible keyboard focus, useful links, keyboard operation, reduced-motion and print CSS. Core content works without JavaScript. Responsive 1440/768/390/360px. No remote fonts, external JS, analytics or chart services.
